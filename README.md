# Alzikrayat

## Requirements
- PHP
- MySQL/MariaDB
- Apache or another PHP server

## Database Setup

1. Create a database named `alzikrayat`.
2. Import the provided database SQL file.
3. Open `config/database.php`.
4. Update the database settings according to your local environment.

Example:

- Host: localhost
- Database: alzikrayat
- Username: root
- Password: your local database password

## Running the Project

1. Place the project in your web server directory.
2. Start Apache and MySQL/MariaDB.
3. Configure `config/database.php`.
4. Open the project in your browser.
